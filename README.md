# FastDesk_Browser

مرورگر اندرویدی FastDesk Browser با تمرکز بر نمایش وب در حالت دسکتاپ، کنترل موس روی صفحه، تب‌ها، جست‌وجو، نشانک و تاریخچه، دانلود و ابزارهای کاربردی وب.

## مشخصات پروژه

- Repository: `FastDesk_Browser`
- Application ID: `com.gapgpt.fastdeskbrowser`
- Namespace: `com.gapgpt.fastdeskbrowser`
- Min SDK: Android 6.0 (API 23)
- Target SDK: 28
- Compile SDK: 35
- Java: 17
- Version: 1.0.0

## قابلیت‌های اصلی

- WebView با JavaScript و DOM Storage برای سایت‌های پویا.
- حالت دسکتاپ با User-Agent دسکتاپ و viewport گسترده.
- زوم طبیعی WebView با دو انگشت.
- نشانگر موس زرد روی صفحه با پنجرهٔ موس شناور، حرکت، مرکز کردن، تغییر اندازه و کلیک چپ جداگانه.
- با بسته‌شدن پنجرهٔ موس، نشانگر صفحه نیز حذف می‌شود.
- تب‌ها و نوار تب افقی.
- بازگشت و جلو، جست‌وجو، نشانک‌ها و تاریخچه.
- دانلود، اشتراک، ذخیرهٔ متن/HTML/PDF/JPG و آپلود فایل.
- حالت کم‌مصرف/فقط متن، کنترل JavaScript، پاک‌کردن cache و کوکی‌ها.
- موتورهای جست‌وجوی قابل انتخاب.
- صفحهٔ خانه با میان‌برهای وب و منابع رادیو/تلویزیون آنلاین.

## ساخت APK در GitHub

فایل `.github/workflows/android.yml` برای Build خودکار APK تنظیم شده است. پس از قرار دادن فایل‌های این پروژه در یک Repository تازه، اولین Commit را انجام دهید و Workflow را از بخش Actions اجرا کنید.

## نکتهٔ مهم درباره Repository

این بسته عمداً بدون پوشهٔ `.git` ساخته شده است تا هیچ Commit، remote، branch یا سابقه‌ای از پروژهٔ قبلی وارد Repository جدید نشود. این ZIP باید به‌عنوان اولین محتوای Repository جدید استفاده شود.

## محدودیت‌های وابسته به WebView

سازگاری سایت‌های سنگین، DRM، برخی سرویس‌های احراز هویت و قابلیت‌های اختصاصی مرورگر به WebView و دستگاه وابسته است. دانلودهای رمزگذاری‌شده یا محدودشده توسط سایت دور زده نمی‌شوند.
